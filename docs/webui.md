# WebUI 使用与故障排查

## 页面

「总览」显示独立后端的服务总量、趋势与进程。「插件」将后端清单和启动探针的证据合并，即使没有运行对象普查，也能看到插件。点击名称打开详情抽屉，按 Escape 关闭。

「启动记录」可选择历史批次，按插件名称与阶段筛选。导入、构造、初始化分开记录；主进程 RSS + Swap 和服务 anon + Swap 是不同口径。

「诊断」显示进程内的诊断结果。后端模式下会自动保存轻量诊断快照，重载后也能看到最近一次结果；对象普查仍需在 AstrBot 内嵌页手动运行。独立页可以查看后端保存的快照，但不能立即触发 AstrBot 进程内扫描。

「对照」只在后端明确开放实验时允许创建。先选插件和轮数，勾选说明，再确认具体重启次数。刷新不会清空已经填写的选项。结果是当前插件组合下的条件收益。

## 外观

右上角的主题按钮可以打开配色预览，选择后立即应用并保存：

- **松纸**：暖纸底色、墨绿操作、陶朱点缀，适合白天。
- **极夜**：深墨底色、冰蓝数据、薄荷操作与琥珀提示。
- **暮映**：夜紫底色、鸢尾数据、杏金操作与玫瑰点缀。

导航和浮层采用半透明磨砂效果，数据区保留稳定底色。主题面板支持上下方向键、Enter 选择、Escape 关闭，也可点击外部关闭。

## 趋势图

默认查看最近一小时，纵轴自动适应当前范围；也可选择 15 分钟、6 小时、24 小时或本次启动。历史只包含后端实际保留的采样，不补造缺失数据。

- 悬停或点击查看采样时间与数值。
- 电脑上拖动选择区间放大，点击「复位」还原。
- 聚焦图表后，左右方向键逐点查看，Escape 复位。
- 「从零开始」适合看绝对量级；关闭后更容易观察小幅变化。
- 长范围会保留峰谷后缩减显示点；断点不会补成零。最大、最小和区间变化基于当前显示点。

## 刷新与数据源

默认每 15 秒刷新，也可改成 60 秒或暂停。隐藏浏览器标签页、打开确认框、正在诊断时暂停自动刷新。只有一个刷新循环，不启动本地对象扫描，不额外写入本地采样。

已配置后端但连接失败时，显示错误或标记上次成功数据；不会悄悄切换成零数据的本地模式。完全没有配置后端时，才进入本地模式。

服务重启后，总览和插件清单跟随新的批次；旧批次可在启动记录中查找。后端插件清单通常每分钟同步一次。页面里的「采样于」是采样时间，不是浏览器刷新时间。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 后端连接配置不完整 | 检查配置文件路径及 AstrBot 运行用户是否有读取权限 |
| 后端不可达 | 在服务器检查 `systemctl status memoryscope`；不要把后端端口公开到公网 |
| 插件有名称但增量为 `—` | 该插件尚无启动测量，不代表没有占用；检查早期探针是否接入 |
| 诊断显示旧结果 | 查看结果旁的测量时间；自动快照默认每 15 分钟更新，想立即更新可在 AstrBot 插件页运行工具 |
| 页面提示接口不存在 | 后端和插件需配套更新；更新后重载 MemoryScope 插件并刷新浏览器 |
| 明细 PSS 比主图旧 | PSS 比总体采样频率低，悬停查看它自己的采样时间 |

独立页主题和语言存于浏览器偏好设置；AstrBot 沙盒禁止浏览器存储时，内嵌页通过插件 KV 保存登录用户的主题和语言。独立页凭据仅存在当前页面内存，刷新后需重新输入；内嵌页由插件服务端持有后端凭据。

## 开发验证

```sh
python -m pytest -q
python -m ruff check observer core/observer_api.py core/observer_client.py tests/test_observer_trend.py
```

浏览器测试需要 Playwright Chromium：`python -m playwright install chromium`。设置 `MEMORYSCOPE_QA_DIR` 可保存桌面和手机截图。

`pages/memory/index.html` 与 `observer.html` 共用 `app.js`、`model.js`、`chart.js`、`locale.js` 和 `style.css`。内嵌页通过 AstrBot SDK 转发接口，独立页访问后端 HTTP API。不使用远程字体、CDN 或图表依赖。
